# Internationalization

Tower Map uses English as the primary technical and repository language, with
Japanese as the first localized product layer.

## Routes

```text
/                 English default
/methodology      English default methodology
/profile/[slug]   English default tenant profile

/en               English localized route
/en/methodology
/en/profile/[slug]

/ja               Japanese localized route
/ja/methodology
/ja/profile/[slug]
```

The root English routes are kept for compatibility. New language-aware links may
prefer `/en` and `/ja`.

## Dictionary

Localized interface copy lives in `lib/i18n.ts`.

The dictionary covers:

- navigation labels
- homepage copy
- tower controls
- directory labels
- methodology framework
- tenant profile labels
- Japanese floor labels
- Japanese category labels

## Fallback Rule

Not every editorial field is translated immediately.

When Japanese copy is missing, Tower Map falls back to English rather than hiding
content. This keeps the product complete while allowing the editorial layer to be
reviewed gradually.

Fallback fields may include:

- tenant descriptions
- floor narratives
- signal bands
- long-form curator notes
- source names

## Tone

English UI should feel editorial, architectural, and concise.

Japanese UI should stay clear and usable, with a slightly softer tone. Public
social updates can be more diary-like, but the product interface should remain
calm and readable.

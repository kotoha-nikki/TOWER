# Project Overview

Tower Map is an editorial high-rise map of the Solana ecosystem.

The core metaphor is a building:

- each floor represents a level of market gravity and cultural signal
- each tenant represents a project, token, community, or narrative cluster
- the public map lets visitors move through the ecosystem visually
- tenant profiles preserve context beyond a simple price chart

## Narrative

Most crypto directories read like lists. Tower Map reads like a city building.

Projects do not only have prices. They have neighbors, floors, history, heat,
liquidity, and public memory. Tower Map uses that structure to make the Solana
ecosystem easier to scan and more memorable to explore.

## Current Product Surface

Tower Map is designed around these public and interactive surfaces:

- public tower map
- clickable floors
- tenant directory
- tenant profile pages
- methodology page
- Japanese language layer
- 350+ tenant registry
- wallet login
- saved tenants
- public save counts
- tenant notes
- moderation and safety workflow

## Positioning

Tower Map is not a trading terminal.

It is a curated reading layer for ecosystem attention:

- what is visible
- what is culturally loud
- what has lasting gravity
- what is still moving into the building

## Tone

The project should feel editorial, architectural, and quietly technical.

It should not feel like a casino, a launchpad, or a generic token tracker.

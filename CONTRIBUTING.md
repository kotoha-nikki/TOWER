# Contributing

Tower Map is an editorial ecosystem map. Contributions should improve the clarity,
accuracy, structure, or usability of the tower.

## Contribution Principles

- Keep the project language professional and concise.
- Use English for code, file names, commits, and technical documentation.
- Keep Japanese notes intentional and limited to cultural or builder-diary surfaces.
- Do not add stablecoins, wrapped assets, LP tokens, tokenized stocks, or treasury products as normal tenants.
- Do not invent contract addresses or market data.
- Prefer verifiable sources when adding tenant metadata.

## Tenant Data Guidelines

Tenant additions should include:

- project name
- ticker
- category
- assigned floor
- short description
- source or reference
- contract address status

Contract addresses should be marked as pending unless verified from an official source.

## Commit Style

Use short English commit messages:

```text
Initialize Tower Map foundation
Add tower methodology notes
Add tenant data model draft
Prepare wallet identity layer
```

## Pull Request Checklist

- The change matches the Tower Map narrative.
- Data additions avoid duplicates.
- Public copy stays clear and non-promotional.
- No secrets or private keys are committed.
- Documentation is updated when behavior changes.
